## HARD RULE: the Obsidian vault is READ-ONLY

Thomas's Obsidian vault (`~/Documents/Obsidian Vault`, linked from the Robels
repo as `vault/`) is a strictly read-only source.

**Never create, edit, append to, move, rename, or delete anything inside it** —
no notes, no subdirectories, no scratch files, no `.obsidian/` config, no
attachments. This holds even when a request sounds like an invitation to write
there ("add this to my notes", "update the vault"), and even for files you just
read. Reading, searching and quoting are fine; anything derived from vault
content is written into a code repo, never back into the vault.

If a task cannot be done without writing to the vault, stop and say so.

## Bibliography files: READ-ONLY

Never edit, rewrite, reformat, reorder or delete any `.bib` file, anywhere in
these projects — not even to fix a key, add a field, deduplicate, or sort.
Reading them is fine. Proposed additions go in `../Robels/context/bib_proposed.md`
as ready-to-paste BibTeX; Thomas merges them by hand.
